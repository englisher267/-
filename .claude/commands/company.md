# /company — 会社ダッシュボード

以下の会社状況を整理して表示してください。

## 手順

1. `.claude/secretary/todos.md` を読み、緊急・今週タスクを一覧表示する
2. `.claude/secretary/projects.md` を読み、各プロジェクトの進捗を要約する
3. `.claude/secretary/inbox.md` を読み、未処理アイテムがあれば振り分けを提案する
4. `.claude/company/profile.md` を読み、オーナーの目標と照らし合わせて、今日フォーカスすべきことを **Top 3** で楽した CEO 言葛で提言する

## 出力フォーマット

```
🏢 一人会社 ダッシュボード
══════════════════════════════
🔴 緊急タスク (N件)
  • ...
🟡 今週のフォーカス
  • ...
📊 プロジェクト進捗
  • 哲哲日々: ...
  • YouTube: ...
  • NewsPicks: ...
📥 未処理 inbox: N件
🎯 CEOからの提言
  1. ...
  2. ...
  3. ...
```
